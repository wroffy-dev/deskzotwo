# Open Questions for the Deskzo Team

> **Do not upload this file to Open WebUI.** It is for the Deskzo team, not for end users. It names code locations so each point can be checked quickly.

These are points where the code was unclear, looked unfinished, or disagreed with Deskzo's own help-guide drafts (the help-guide drafts in the repository). Where the guide and the code disagreed, the knowledge base follows the **code**. Please confirm or correct each point, then update the matching knowledge file.

## Most important to confirm first

1. **Deskzo Android app** — the app is real, but Settings → Deskzo app only appears once the app is released, and some Play Store steps are still to do. `mobile-app.md`, `00-overview.md` and `faq.md` say the app exists and that the Settings page shows when it is available. Confirm the release state and fill in the [LINK] placeholder.
2. **Automate is still being built** — the Automate guide itself says so, and Automate is currently open only to people with *Change organisation settings*. Check both `automate-*.md` files against the live screens before publishing them.
3. **Customer inbox has no guide draft** — `support-customer-inbox-*.md` was written from code alone. Deskzo AI answers in the inbox and the WhatsApp setup looked unfinished; please review closely.
4. **Super-admin deletes** — guides say leads, companies and tickets can't be deleted; the code lets the super admin delete them. The knowledge base follows the code.
5. **Export permissions vs. buttons** — Lead export and item import/export need permissions (*Export customer data*, *Import the catalog*, *Export the catalog*) that the buttons do not check before showing. Some error messages name a permission label that doesn't exist ("Export CRM data").
6. **Products that need a module they don't include** — Forecast (in Deskzo Analytics) needs Leads, which Analytics doesn't sell; Payments (in Deskzo Books) records against Orders, which Books doesn't sell. Confirm the intended behaviour for single-product customers.
7. **Renewals guide is out of date** — renewal manager, "Lapsed — not renewed", Settings → Renewals and the Renewal report exist in code but not in the guide.
8. **Reporting manager inheritance** — the add/edit user forms say a manager "also gets every permission they hold"; elsewhere the code says managers no longer inherit. The knowledge base leaves the claim out.
9. **Placeholders to fill** — every `[PRICING: …]`, `[POLICY: …]`, `[CONTACT: …]` and `[LINK: …]` in the knowledge files (about 46 in total). Search the folder for "to be filled by Deskzo team".
10. **File sizes** — four files are 11–76 words over the ~2,000-word target (`crm-leads.md`, `books-items-and-inventory.md`, `projects.md`, `01-getting-started.md`). They were kept whole; split them if your chunking needs it.
